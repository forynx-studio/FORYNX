# FORYNX — تعليمات الموقع

## المحتويات
- `index.html`: الصفحة الرئيسية وكل أقسام الموقع.
- `styles.css`: التصميم والألوان والتجاوب.
- `script.js`: قائمة الجوال وسنة حقوق النشر.
- `assets/forynx-logo.png`: الشعار الأصلي.
- `assets/favicon.png`: أيقونة التبويب.
- `robots.txt`: تعليمات محركات البحث.

## تشغيل الموقع
1. فك ضغط ZIP.
2. افتح `index.html` في المتصفح للمعاينة. يحتاج الخط المستخدم اتصالًا بالإنترنت؛ في غيابه سيظهر خط بديل.
3. عدّل النصوص والأسعار والروابط في `index.html` عند الحاجة.
4. عدّل الألوان من المتغيرات أعلى `styles.css`.

## النشر باستخدام GitHub وSevalla
1. أنشئ مستودع GitHub جديدًا. ارفع ملفات الموقع ومجلد `assets` بحيث يكون `index.html` في جذر المستودع، وليس داخل مجلد إضافي.
2. سجّل الدخول إلى Sevalla، واختر إنشاء Static Site واربط حساب GitHub بالمستودع.
3. اختر الفرع الرئيسي. للموقع الثابت بدون إطار عمل لا يلزم أمر بناء؛ عيّن مجلد النشر إلى جذر المشروع (`.`) إذا طلبت المنصة ذلك، وفق إعدادات الواجهة الحالية.
4. انشر الموقع وافتح الرابط الذي تعطيه Sevalla واختبر جميع الأقسام والروابط.
5. بعد تعديل الملفات ورفعها إلى الفرع المرتبط، أعد النشر أو انتظر النشر الآلي بحسب إعدادات حسابك.

## التواصل
- أزرار طلب الباقات تفتح واتساب الرقم `+966550951881` مع رسالة جاهزة.
- روابط TikTok وX وواتساب المباشر مضافة في التذييل.
- **لا يوجد نموذج إرسال بريد** في هذا الإصدار، ولا قاعدة بيانات أو لوحة تحكم أو دفع إلكتروني. كل زر تواصل هو رابط حقيقي خارجي.

## SEO
- تمت إضافة عنوان ووصف أساسيين ووسوم المشاركة وصورة وأيقونة.
- بعد شراء وربط دومين نهائي، أنشئ `sitemap.xml` باستخدام روابط الدومين الحقيقية وأضف مساره في `robots.txt`، واضبط رابط `canonical` و`og:url` بعنوان الدومين الحقيقي، ثم اربط Google Search Console.
- لا يمكن ضمان ترتيب معين أو فهرسة فورية.

## ملاحظات قبل التسليم للعملاء
- أسعار الباقات والنطاق المعروض في الموقع مقترحات تحتاج اعتماد صاحب المشروع.
- أي نموذج تواصل مستقبلي يحتاج خدمة إرسال خارجية واختبارًا حقيقيًا؛ لا تضع مفاتيح سرية في GitHub.
- أوقات خدمة العملاء المعروضة من 12 ظهرًا إلى 12 مساءً (منتصف الليل) كما في المعلومات السابقة؛ راجعها قبل النشر.
- اختبر نسخة الجوال، وجميع الروابط، والتباين، والمحتوى النهائي بعد النشر.


## دعم العربية والإنجليزية
- `index.html` النسخة العربية باتجاه RTL.
- `en.html` النسخة الإنجليزية باتجاه LTR.
- زر `EN` في الترويسة ينقلك للإنجليزية، وزر `عربي` يعيدك للعربية.
- كل لغة لها عنوان ووصف SEO خاص بها.
- **مهم:** عند تعديل محتوى الموقع، حدّث النصوص في الملفين للحفاظ على تطابق اللغتين.
- ارفع `en.html` مع بقية الملفات في جذر المستودع.
- أزرار طلب الباقات في النسخة الإنجليزية تفتح واتساب برسائل باللغة الإنجليزية.
